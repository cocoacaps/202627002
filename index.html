Learning About HTML and HTTP

HTML and HTM

HTML

HTML stands for HyperText Markup Language. It is used to create and structure webpages.

HTM

HTM is a shorter file extension for HTML. Both .html and .htm files can contain HTML code.

HTTP and HTTPS

HTTP

HTTP stands for HyperText Transfer Protocol. It allows a browser and a web server to communicate.

HTTPS

HTTPS stands for HyperText Transfer Protocol Secure. It uses encryption to help protect information.

Quiz

Question 1

What is the difference between HTML and HTM?

Answer: HTM is a shorter file extension for HTML.

Question 2

What is the main difference between HTTP and HTTPS?

Answer: HTTPS uses encryption to help protect information.
